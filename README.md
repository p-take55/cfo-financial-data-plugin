# 財務データ管理

数字の収集と更新、請求と入金の照合、商品・顧客・案件別の表づくりの 3 つの Skill。CFO の財務データ管理の部分を切り出したもの。

[CFO](https://github.com/p-take55/aachat-cfo) の Skill のうち、財務データ管理にあたるものを Plugin にまとめたものです。単独で入れても使えます。

## 同梱の Skill

| Skill | すること |
|---|---|
| `cfo-data-refresh` | 会計・請求・決済の数字を集めて更新する |
| `cfo-data-check` | 請求と入金、残高を突き合わせる |
| `cfo-data-model` | 商品・顧客・案件別に分析できる表に整える |

## 使うときに

数字の元になる資料、扱う事業・期間・通貨、守りたい残高や使える予算を、要る範囲で渡してください。手元の資料からでも、使える接続からでも始められます。

- 実績・予定・仮定、利益と入出金、本人の工数を分けて扱い、分からない金額をゼロで埋めません。
- 外部サービスとつなぐ設定（MCP・認証）、定期実行、通知は同梱していません。
- 送金・注文・支払・借入・投資の取引・税の申告・契約の変更・外への送信はしません。この Plugin を入れたことを、それらの許可とは受け取りません。
